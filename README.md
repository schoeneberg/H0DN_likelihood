This repository contains the likelihood extension of the code associated with the H0 Distance Network paper. All credit goes to the original repository, which is available at https://github.com/StefCas789/H0DN.

The original paper is available at:
 - https://arxiv.org/abs/2510.23823
 - https://doi.org/10.1051/0004-6361/202557993
 - https://ui.adsabs.harvard.edu/abs/2025arXiv251023823H/abstract
 - https://www.aanda.org/articles/aa/full_html/2026/04/aa57993-25/aa57993-25.html

Explanations about the sub-folders can also be found in the original README.md of the original repository.

The folder "idlcode" contains the original code, written in IDL (8.0 or higher) for Unix-like operating systems. 
See the README files in that folder for instructions on how to reproduce the results in the published paper.
The folder "h0_constrainer" contains the Python implementation. See the README in that folder for instructions.
The folder "data" contains the data needed to reproduce the main results in the paper.
