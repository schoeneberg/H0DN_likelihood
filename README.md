This repository contains the code associated with the H0 Distance Network paper, which explains how to set up a distance network for the determination of the local value of the Hubble Constant (H0).  
The main paper is available on arXiv (URL https://ui.adsabs.harvard.edu/abs/2025arXiv251023823H/abstract) and will be published on April 10, 2026 in Astronomy and Astrophysics.
The folder "idlcode" contains the original code, written in IDL (8.0 or higher) for Unix-like operating systems.  See the README files in that forder for instructions on how to reproduce the results in the published paper.
The folder "data" contains the data needed to reproduce the main results in the paper.
